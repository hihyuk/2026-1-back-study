6주차에서는 유효성 검사, 예외 처리, swagger를 학습했다. 유효성 검사는 요청으로 들어오는 데이터가 올바른 형식인지 검사하는 것이다. @NotNull, @Size, @Pattern 등의 유효성 검사 어노테이션을 적용하고 Controller 메서드에 @Valid를 추가하여 사용할 수 있다. 예외 처리는 에러 발생 시 원인을 알려주는 에러 메시지를 커스텀하여 응답 객체를 생성하는 것이다. 실습에서 GlobalExceptionHandler.java, ErrorResponse.java 파일을 추가하여 전역 예외 핸들러를 구현했다. 또, BadRequestException.java, NotFoundException.java를 추가해서 커스텀 예외 처리도 해주었다. 마지막으로 Swagger UI를 사용하여 API 문서를 생성해봤다.
